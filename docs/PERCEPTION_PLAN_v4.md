## 域 A：GLB/网格/几何处理（纯函数路线——精准/细/强/显存 0）

| 技术 | ★ | 语言 | 精准 | 细 | 强 | 显存 | 特点 | 缺点 |
|---|---|---|---|---|---|---|---|---|
| **assimp** | 13.1k | C++/Rust绑定 | ★★★★ | ★★★ | ★★★★★ | 0 | 全格式导入（glTF/obj/fbx），业界标准 | 大而全，重；只导入不分析 |
| **cgltf** | 2.0k | C（单文件） | ★★★★★ | ★★★★ | ★★★★ | 0 | **单文件无依赖 glTF 解析**，最快最准 | 只读；要自己写分析 |
| **tinygltf** | 2.5k | C++ | ★★★★ | ★★★★ | ★★★★ | 0 | 成熟 glTF 读写 | C++ 依赖 |
| **libigl** | 5.1k | C++ | ★★★★ | ★★★★★ | ★★★★★ | 0 | 几何处理算法库（拉普拉斯/参数化/形变） | C++ 重 |
| **CGAL** | 6.0k | C++ | ★★★★★ | ★★★★★ | ★★★★★ | 0 | **计算几何黄金标准**（网格修复/布尔/骨架） | 超重，编译噩梦 |
| **pmp-library** | 1.5k | C++ | ★★★★ | ★★★★ | ★★★★ | 0 | 多边形网格处理（简化/平滑/修复） | 生态小 |
| **meshio** | 2.3k | Python | ★★★ | ★★★★ | ★★★ | 0 | 格式转换 IO | 只 IO 不分析 |
| **PyMeshLab** | 970 | Python | ★★★★ | ★★★★ | ★★★★ | 0 | MeshLab 算法绑定（修复/简化/测量） | 包大 |
| **pyvista** | 3.8k | Python | ★★★★ | ★★★★★ | ★★★★ | 0 | 3D 可视化+分析（网格查询/布尔/测量） | Python 重 |
| **trimesh** | 3.6k | Python | ★★★★ | ★★★★★ | ★★★★ | 0 | **网格分析首选**（退化三角/非流形/空洞/体积） | Python |
| **Open3D** | 13.9k | Python/C++ | ★★★★ | ★★★★ | ★★★★★ | 0-2G | 点云/重建/可视化全套 | 1GB+ 依赖 |
| **geometry-central** | 1.3k | C++ | ★★★★★ | ★★★★★ | ★★★★★ | 0 | 现代几何处理（方向场/测地线） | 小众 |
| **draco** | 7.4k | C++ | ★★★★ | ★★★★ | ★★★★★ | 0 | **Google 网格压缩**（GLB 内嵌） | 只压缩 |

### 决策（四维打分后）

| 用途 | 选谁 | 理由（精准/细/强/显存） |
|---|---|---|
| **GLB 解析（glb_info）** | **cgltf**（Rust 调 C）或 **gltf-rs** | 精准★★★★★ / 细★★★★ / 单文件无依赖 |
| **网格质量（mesh_check）** | **trimesh**（Python 桥） | 退化三角/非流形/空洞/体积全查，细★★★★★ |
| **网格修复（高级）** | **pmp-library / CGAL**（P2） | 强★★★★★，但要 C++ 编译 |
| **GLB 体积优化** | **draco**（压缩检查） | 强★★★★★，查"压缩率异常" |

**结论：P0 用 cgltf/gltf-rs + trimesh，纯 CPU 0 显存，四维达标。**

| **MiniCPM-V 4B** | 26.2k | ★★★★ | ★★★★ | ★★★★ | **~3G** | 端侧多模态，内置 OCR，中文强 | UI 专精一般 |
| **Qwen3-VL 2B** | 19.8k | ★★★★ | ★★★★ | ★★★★ | **~1.5G** | 2026 开放 SOTA，可微调 | 通用非 UI 专精 |

### 决策

| 用途 | 选谁 | 理由 |
|---|---|---|
| **UI 元素识别（截图→元素列表）** | **OmniParser 思路**（P1，若显存允许按需加载）| 精准+细（元素级框/文本/图标） |
| **UI 描述/判断（常驻）** | **Qwen3-VL 2B INT4**（1.5G 常驻）| 四维均衡，显存达标 |
| **中文 UI 文本** | MiniCPM-V 4B 备选 | 中文强 |
| **UI 结构（无模型）** | **ui_tree_dump 纯函数**（P0）| 显存 0，最精准（代码级真相） |

**结论：P0 纯函数树（0 显存最精准）→ P1 Qwen3-VL 2B 常驻 + OmniParser 按需。**

| **NIMA**（论文 TIP'18，实读） | ★★★★ | ★★★★ | ★★★★ | CPU | **预测人类评分分布**（1-10 分布而非均值），单图无参考 |

| 用途 | 选谁 | 理由 |
|---|---|---|
| **截图 OCR（中文游戏 UI）** | **PaddleOCR**（CPU）| 中文精准★★★★★ |
| **游戏画面质量分（模糊/噪点）** | **NIMA/BRISQUE**（CPU）| 无参考、单图、显存 0——"截图清晰度"自动判定 |

**结论：OCR 用 PaddleOCR（CPU 0 显存，中文最强）；质量用 NIMA（0 显存，无参考）。**

### 蒸馏链（最终形态——"训练小模型"）
