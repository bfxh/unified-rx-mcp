# Mechanist 机制发现吸收（AI 机制自动发现工具）

> 来源：用户分享的 Mechanist 介绍（AI 机制自动发现工具）。

## 核心吸收

1. **核心目标**：解决"AI 能力增长快、人类理解慢"矛盾——发现**神经元层面作用机制**（黑盒→透明对象）。
2. **工作方式**：4300 万篇跨学科文献 + 可解释性论文 → **"提出假设 → 执行实验 → 验证结论"自动化闭环**。
3. **优势**：假设质量优于现有自动化代理；定位信念/推理相关神经元；支持干预与控制。
4. **应用边界**：AI 帮人类理解 AI；仍需人类设定目标与审查结果。

## 前沿方向（吸收）

- **多模态风险识别**：阻断内部传递通道（跨模态风险信号拦截）
- **信念机制定位**：发现特定注意力头对"信念"至关重要

## 映射到 unified-rx-mcp

| Mechanist 概念 | 我们的落地 |
|---|---|
| 假设生成 | `mechanist_probe`：从训练数据/扫描发现提炼候选机制假设 |
| 实验执行 | 用现有工具跑验证（bug_scan/unit_rerun/训练数据回放） |
| 验证结论 | 机制报告（假设 → 证据 → 结论/置信度） |
| 跨模态风险识别 | scan 系（bug_scan/cross_taint——跨层风险信号） |
| 信念机制定位 | 规则权重（learn_weights——高频模式=机制信号） |

## mechanist_probe 工作流

```
输入：模块/现象（如 bug_scan 高频问题）
→ ① 假设生成（从 samples/rules 提炼）
→ ② 实验列表（验证手段：扫描/测试/数据回放）
→ ③ 结论（证据支持度 + 置信度）
```
