# 视觉原语研究落地（DeepSeek Thinking with Visual Primitives）

> 来源：DeepSeek 多模态技术报告（2026-05）——"以视觉原语思考"。

## 论文核心

1. **视觉原语（Visual Primitives）**：点（point）与边界框（bbox）作为**思维单元**嵌入 CoT（思维链）——模型用"指图"而非纯文字推理（"指图说话"）。
2. **空间参照难题**：传统多模态模型无法精确指认位置——原语机制破解（bbox 精确锚定）。
3. **On-Policy 蒸馏四段式管线**（对齐我们的蒸馏策略）：
   - ① 专家 SFT（监督微调——高质量标注数据）
   - ② 专项 RL（强化学习——按能力域）
   - ③ 统一 RFT（拒绝采样微调）
   - ④ **蒸馏**（教师→学生小模型）

## 对我们的应用映射（建模/动画/UI 空间推理）

| 论文概念 | 我们的应用 |
|---|---|
| 点/bbox 思维单元 | 训练样本的**视觉原语标注**：模块连接点坐标、动画路径锚点、UI 元素 bbox |
| CoT 嵌入 | 修复样本加"空间推理链"（位置→原因→修复） |
| On-Policy 蒸馏 | 蒸馏策略：bug/fix 对作 DPO 偏好 + 四段式管线（SFT→RL→RFT→蒸馏） |

## 视觉原语标注格式（训练样本扩展）

```json
{
  "visual_primitives": [
    {"type": "point", "coords": [x, y, z], "label": "连接点"},

  ]
}
```
